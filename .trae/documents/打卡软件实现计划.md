# 打卡软件实现计划

## 一、数据模型设计

1. **DayData** - 存储每天的状态
   - date: LocalDate - 日期
   - isWorkday: Boolean - 是否为工作日
   - isCheckedIn: Boolean - 是否已打卡
   - isRestDay: Boolean - 是否为休息日

2. **MonthStats** - 存储月度统计信息
   - totalDays: Int - 当月总天数
   - workdays: Int - 当月工作日天数
   - checkedInDays: Int - 已打卡天数
   - restDays: Int - 休息天数
   - targetPercentage: Float - 目标打卡比例
   - currentPercentage: Float - 当前打卡比例
   - daysToTarget: Int - 距离达标还需天数

## 三、功能实现

### 1. 日历生成与显示
- 使用`java.time`包处理日期
- 生成当前月份的日历
- 标记周末和法定节假日

### 2. 打卡功能
- 点击日历中的日期进行打卡
- 支持设置工作日/休息日
- 实时更新统计信息

### 3. 统计计算
- 计算当月工作日天数
- 计算已打卡天数
- 计算休息天数
- 计算当前打卡比例
- 计算距离达标还需天数

### 4. 撤销功能
- 记录打卡历史
- 支持撤销最近的打卡操作
- 撤销后更新统计信息

### 5. 数据持久化
- 使用`DataStore`存储打卡记录
- 存储目标打卡比例设置
- 应用重启后恢复数据

## 四、状态管理

使用Compose的状态管理机制：
- `mutableStateOf` - 管理UI状态
- `remember` - 保存状态
- `LaunchedEffect` - 处理副作用
- `ViewModel` - 管理业务逻辑和数据
