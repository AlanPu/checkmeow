# CheckMeow - 个人打卡应用

## 项目简介

CheckMeow是一款基于Android平台的个人打卡应用，使用Kotlin和Jetpack Compose开发，帮助用户记录每日打卡情况，追踪打卡进度，实现个人目标管理。

## 核心功能

### 1. 日历视图
- 直观的月度日历展示
- 支持月份切换
- 清晰标识已打卡、休息日和普通工作日

### 2. 打卡功能
- 点击日期进行打卡/取消打卡
- 长按日期设置/取消休息日
- 休息日自动标记为不可打卡

### 3. 目标管理
- 可设置目标打卡比例（10%-100%）
- 实时显示当前打卡比例
- 计算距离达标还需打卡天数

### 4. 统计分析
- 显示当月总天数、工作日数、已打卡天数、休息天数
- 展示目标打卡比例和当前打卡比例
- 达标状态可视化（绿色表示达标，红色表示未达标）

### 5. 数据管理
- 导出打卡数据为JSON文件
- 导入JSON文件恢复打卡数据
- 数据持久化存储

## 技术实现

### 技术栈
- **开发语言**：Kotlin
- **UI框架**：Jetpack Compose
- **数据存储**：DataStore
- **JSON处理**：Gson
- **日期处理**：LocalDate/YearMonth

### 项目结构

```
app/src/main/java/top/alanpu/checkmeow/
├── data/
│   └── CheckInRepository.kt        # 数据持久化处理
├── model/
│   ├── CalendarUtil.kt             # 日历生成和统计计算
│   ├── DayData.kt                  # 单日数据模型
│   ├── ExportData.kt               # 导出数据模型
│   └── MonthStats.kt               # 月度统计模型
├── ui/
│   └── theme/                      # 主题相关
└── MainActivity.kt                 # 应用主入口
```

### 核心组件

1. **CheckInApp**：应用主组件，包含所有功能逻辑
2. **MonthHeader**：显示月份标题和统计信息
3. **TargetPercentageSlider**：目标打卡比例设置滑块
4. **CalendarView**：日历视图，显示日期和打卡状态
5. **DayItem**：单个日期项，支持点击打卡和长按设置休息日
6. **ActionButtons**：操作按钮，包括导出、导入和刷新

## 使用方法

### 基本操作
1. **打卡**：点击日历中的日期
2. **设置休息日**：长按日历中的日期
3. **切换月份**：点击月份标题两侧的箭头按钮
4. **调整目标打卡比例**：拖动滑块设置目标比例
5. **导出数据**：点击"导出"按钮，选择保存位置
6. **导入数据**：点击"导入"按钮，选择JSON文件
7. **刷新数据**：点击"刷新"按钮重新加载数据

### 数据导出格式

导出的JSON文件包含以下信息：

```json
{
  "targetPercentage": 40.0,
  "checkInData": [
    {
      "date": "2023-06-01",
      "isCheckedIn": true,
      "isRestDay": false
    },
    {
      "date": "2023-06-02",
      "isCheckedIn": false,
      "isRestDay": true
    }
  ]
}
```

## 安装与运行

### 前提条件
- Android Studio
- Android SDK 21+
- Kotlin 1.8+

### 运行步骤
1. 克隆项目到本地
2. 在Android Studio中打开项目
3. 同步Gradle依赖
4. 运行应用到模拟器或真实设备
